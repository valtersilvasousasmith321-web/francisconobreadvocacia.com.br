Página de uso interno — não compartilhe este link. Esta página publica artigos diretamente no seu repositório do GitHub usando um token de acesso. O token fica salvo apenas neste navegador (nunca é enviado a nenhum servidor além do próprio GitHub). Ainda assim, trate-a como uma senha: não mande o link nem prints dela para ninguém.

1. Conexão com o GitHub

Fica salvo só neste navegador.
Como criar o token (primeira vez)
  1. No GitHub, acesse Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Clique em Generate new token.
  3. Em "Repository access", escolha Only select repositories e selecione o repositório deste site.
  4. Em "Permissions", abra Repository permissions e defina Contents como Read and write.
  5. Gere o token e cole aqui. Ele começa com github_pat_.

2. Novo artigo

Cada parágrafo vira um bloco separado no artigo publicado.
Isso publica direto no arquivo blog.html do repositório configurado. O GitHub Pages atualiza o site sozinho, normalmente em menos de 1 minuto.
